#+TITLE: Local Manual Tests
#+STARTUP: showall

To run local tests use the following scheme.

* CLI end-to-end check

Config example, relative paths are relative to the config file:

#+begin_src toml
db_path = "./org-files-db.sqlite"
files = ["~/path/to/notes/example.org", "~/path/to/gtd/example.org"]
dirs = ["~/path/to/notes", "~/path/to/people"]
recursive = true

[search]
fts5_enabled = false
index_body_text = false
#+end_src


Example calls:

** Run rebuild (rebuilds the database):

#+begin_src shell
cargo run --manifest-path /path/to/org-files-db/Cargo.toml --bin orgfdb -- rebuild --config /path/to/config.toml
#+end_src

** Run headings JSON:

#+begin_src shell
cd /path/to/config-directory
cargo run --manifest-path /path/to/org-files-db/Cargo.toml --bin orgfdb -- headings --json
#+end_src

* Example with Org Source Block

** Paths

#+name: cargo-manifest
: ~/path/to/org-files-db/Cargo.toml

#+name: config-path
: ~/path/to/org-files-db/.project/local/config.toml

#+name: output-json
: ~/path/to/org-files-db/.project/local/orgfdb.json

#+name: output-json-with-root
: ~/path/to/org-files-db/.project/local/orgfdb--with-root.json

** Commands

Run rebuild. This rebuilds the database.

#+begin_src shell :noweb yes
cargo run --manifest-path <<cargo-manifest()>> --bin orgfdb -- rebuild --config <<config-path()>>
#+end_src

#+RESULTS:

Write headings JSON.

#+begin_src shell :noweb yes
cargo run --manifest-path <<cargo-manifest()>> --bin orgfdb -- headings --json --config <<config-path()>> > <<output-json()>>
#+end_src

Write headings JSON including the root heading.

#+begin_src shell :noweb yes
cargo run --manifest-path <<cargo-manifest()>> --bin orgfdb -- headings --json --include-root --config <<config-path()>> > <<output-json-with-root()>>
#+end_src
