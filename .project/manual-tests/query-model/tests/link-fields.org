* link-type

** Ein Linktyp

Erwartet:

- zwei Links mit ~link_type = custom-id~ und resolution_status resolved
- ein Link mit ~link_type = custom-id~ und resolution_status broken

#+begin_src shell :noweb yes :results raw :wrap SRC js
  set -o pipefail

  cargo run --quiet --manifest-path <<cargo-manifest()>> --bin orgfdb -- query --json --config <<config-path()>> \
    '(links
       (and
         (source
           (files
             (file-name "link-predicates-source.org" :exact t)))
         (link-type "custom-id")))' \
  | jq '.results[] | {
      link_type,
      raw_target,
      raw_description,
      resolution_status
    }'
