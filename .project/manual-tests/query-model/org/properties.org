* Expected file/root values

The synthetic level-0 file/root object should have these direct effective properties:

- ~ROOT_DRAWER_BASE = root~
- ~ROOT_DRAWER_APPEND = root appended~
- ~ROOT_DRAWER_DUPLICATE = second~
- ~ROOT_OVERRIDE_CHAIN = root~
- ~KEYWORD_APPEND = foo=1 bar=2 baz=3~
- ~KEYWORD_DUPLICATE = second~
- ~KEYWORD_RESET = replacement appended-after-reset~
- ~KEYWORD_APPEND_ONLY = only appended~
- ~KEYWORD_EMPTY = valid~

With ~:inherit nil~, these values match only the file/root object.

With ~:inherit t~, real headings may inherit these values unless a nearer heading defines the same property.
