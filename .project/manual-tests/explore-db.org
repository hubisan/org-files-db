* Suggested workflow

1. Run [[./manual-test.org]] to rebuild the database.
2. Open the specific explore file for the area you want to inspect.
3. Execute the relevant source blocks.
4. Check ~git diff~ for unexpected result changes.

* Notes

Prefer stable query output for committed manual tests:

- Avoid dynamic columns such as ~mtime_ns~ and ~indexed_at~ unless deliberately inspecting them.
- Use stable ~ORDER BY~ clauses.
- Prefer relative or normalized paths in result output when possible.
