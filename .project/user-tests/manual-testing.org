#+TITLE: Local Manual Tests
#+STARTUP: showall

* CLI end-to-end check

Purpose:
Verify that the minimal CLI pipeline works against a local Org setup.

Config example:

#+begin_src toml
db_path = "./org-files-db.sqlite"
files = ["/path/to/notes/example.org", "/path/to/notes/example-1.org"]
dirs = ["/path/to/notes", "/path/to/people"]
recursive = true

[search]
fts5_enabled = false
index_body_text = false
#+end_src

Run rebuild (rebuilds the database):

#+begin_src shell
cargo run --manifest-path /path/to/org-files-db/Cargo.toml --bin orgfdb -- rebuild --config /path/to/config.toml
#+end_src

Run headings JSON:

#+begin_src shell
cd /path/to/config-directory
cargo run --manifest-path /path/to/org-files-db/Cargo.toml --bin orgfdb -- headings --json
#+end_src

Expected result:

- `rebuild` completes successfully.
- Parser diagnostics may be printed as warnings, but should not abort the rebuild unless they are fatal.
- `headings --json` returns stored heading rows.
- Explicit files that are also discovered through dirs should not appear duplicated.
- Level-0/root rows should behave according to the CLI option used.
- Known limitation: heading `title` may still preserve Org markup until title normalization is implemented.
