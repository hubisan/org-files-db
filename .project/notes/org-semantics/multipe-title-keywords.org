#+TITLE: Multiple Title Keywords

[[info:org#Export Settings][org#Export Settings]]

‘TITLE’
     Org displays this title.  For long titles, use multiple ‘#+TITLE’
     lines.

* Example

#+name: example
#+begin_src org
  ,#+TITLE: Title can span
  ,#+TITLE: multiple lines, 
  ,#+AUTHOR: Hubisan

  See [[file:../../notes/org-semantics/multipe-title-keywords.org]]

  ,* Unfortunately Everywhere

  ,#+TITLE: even here

  This can be proven by using ~org-latex-export-as-latex~:

  ,#+BEGIN_SRC latex
    \title{Title can span multiple lines, even here}
  ,#+END_SRC
#+end_src

* Org parse

#+begin_src emacs-lisp :results value code
  (org-sbe "init")
  (orgfdb-parse-named-org-src-block "example")
#+end_src
