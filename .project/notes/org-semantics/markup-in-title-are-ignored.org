#+TITLE: Markup in #+TITLE is ignored
#+STARTUP: showall

Markup like emphasis markers and links in #+TITLE are ignored. Orgice handles this correctly and we will behave the same way as well.

* Example

#+name: example
#+begin_src org
  ,#+TITLE: Invalid *bold* /italic/ _underlined_ =verbatim= ~code~ +strike-through+ [[file:test.org]]

  ,* Valid *bold* /italic/ _underlined_ =verbatim= ~code~ +strike-through+ [[file:test.org]]
#+end_src

* Org parse

#+begin_src emacs-lisp :results value code
  (org-sbe "init")
  (orgfdb-parse-named-org-src-block "example")
#+end_src
