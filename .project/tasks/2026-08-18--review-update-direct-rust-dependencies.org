** sha2 0.11 migration

The project uses the standard ~Sha256~ and ~Digest~ APIs.

The hash operations still compile with ~sha2 0.11.0~, but lowercase output formatting changed through the ~digest 0.11~ output type.

The resolved digest output no longer implements ~LowerHex~, so the existing ~{:x}~ formatting fails to compile.

Keep the existing lowercase hexadecimal representation with a small crate-local byte encoder.

Do not add another dependency only for hexadecimal encoding.

Use the encoder for all SHA-256 strings in production code and benchmark support.

Existing content-hash tests continue to define the expected hash strings.
