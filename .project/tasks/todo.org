** TODO Store materialized outline path

Goal:
Build the ~outline_path~ derived/cache table for fast hierarchy queries.

The table stores:

- ~heading_id~
- ~file_id~
- ~parent_id~
- ~depth~
- ~materialized_path~
- ~breadcrumbs_json~

Example materialized paths:

#+begin_src text
0000
0000.0001
0000.0001.0002
0000.0001.0002.0001
#+end_src

Acceptance criteria:

- One ~outline_path~ row exists per heading.
- Level 0 heading has depth 0.
- Top-level Org headings have depth 1.
- ~materialized_path~ is stable for one rebuild.
- Zero-padding is explicitly defined and enforced (e.g., exactly 4 digits per level to support up to 9999 children).
- ~breadcrumbs_json~ contains titles from level 0 to the current heading.
- Subtree queries can use ~file_id~ and ~materialized_path~.
- A test verifies expected paths for nested headings.

** TODO Consider safe parsing of Emacs `.dir-locals.el` for Org TODO keywords

Goal:
Decide whether `org-files-db` should support directory-local Org TODO keyword
defaults by safely parsing `.dir-locals.el`.

Possible supported subset:

#+begin_src emacs-lisp
((org-mode . ((org-todo-keywords . ((sequence "TODO(t)" "NEXT(n)" "|" "DONE(d)" "CANCEL(c)"))))))
#+end_src

Rules:

- Parse only data, do not evaluate Emacs Lisp.
- Support only `org-mode` / `nil` entries.
- Support only `org-todo-keywords`.
- Support `sequence` first; optionally `type` later.
- Treat keywords before `|` as open and after `|` as closed.
- Preserve fast-selection keys when supported.
- Ignore or warn on unsupported forms.
- Define precedence separately:
  1. file-local `#+TODO:`
  2. nearest supported `.dir-locals.el`
  3. `config.toml`
  4. built-in defaults

Non-goal:
- Do not execute `.dir-locals.el`.
- Do not support arbitrary Emacs directory-local variables.
