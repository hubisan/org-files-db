* Projektziel

Rust org-mode parser (`org-files-db`), der mittels `orgize` Org-Dateien einliest, eine SQLite DB befüllt und ein CLI via `clap` bietet, um Abfragen zu machen (inklusive JSON-API à la org-ql).
