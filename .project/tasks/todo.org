* Phase 3: Org link extractor

** Goal of this phase
:PROPERTIES:
:VISIBILITY: folded
:END:

Extract Org links as raw source facts and store them in SQLite without depending on Orgize's link support being complete. Link resolution to files, headings, IDs, CUSTOM_IDs, org-id-locations, or relationship graphs belongs to later phases.

Core rules:

- Store source facts only.
- Do not resolve link targets in Phase 3.
- Do not execute action-like links such as ~shell:~ or ~elisp:~.
- Keep raw link text and byte ranges as the source of truth.
- Use Orgize for document structure where useful, but do not rely on Orgize as the only source of links.
- Implement a dh-owned raw-text scanner for link tokens.
- Bracket links, angle links, and configured plain links are the supported Phase 3 formats.
- Radio targets, link abbreviations, and relationship extraction are postponed.
- Multi-line bracket links are postponed unless explicitly enabled later.
- Links outside regular headings attach to the synthetic level-0/root heading.
- User-facing CLI output should expose enough source location data for editor jumps.
