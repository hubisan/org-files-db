** TODO Parse properties drawer and file-level properties

Goal:
Extract properties from heading drawers and file-level property declarations.

Sources:

- heading property drawers:
  #+begin_src org
    ,* Task
    :PROPERTIES:
    :ID: abc
    :CUSTOM_ID: task
    :END:
  #+end_src

- file-level property keywords:
  #+begin_src org
    ,#+PROPERTY: Effort_ALL 0:10 0:30 1:00

- Additional properties are preserved.
- Keys are normalized (e.g., converted to uppercase) before DB insertion to handle Org-mode's case-insensitivity.
- Inherited/effective properties are represented or explicitly deferred.
- A test with multiple properties exists.
- A test with file-level properties exists.

** TODO Consider safe parsing of Emacs `.dir-locals.el` for Org TODO keywords

Goal:
Decide whether `org-files-db` should support directory-local Org TODO keyword
defaults by safely parsing `.dir-locals.el`.

Possible supported subset:

#+begin_src emacs-lisp
((org-mode . ((org-todo-keywords . ((sequence "TODO(t)" "NEXT(n)" "|" "DONE(d)" "CANCEL(c)"))))))
#+end_src

Rules:

- Parse only data, do not evaluate Emacs Lisp.
- Support only `org-mode` / `nil` entries.
- Support only `org-todo-keywords`.
- Support `sequence` first; optionally `type` later.
- Treat keywords before `|` as open and after `|` as closed.
- Preserve fast-selection keys when supported.
- Ignore or warn on unsupported forms.
- Define precedence separately:
  1. file-local `#+TODO:`
  2. nearest supported `.dir-locals.el`
  3. `config.toml`
  4. built-in defaults

Non-goal:
- Do not execute `.dir-locals.el`.
- Do not support arbitrary Emacs directory-local variables.
