* Query model v0: revised with link queries

** Core decision

The query language has explicit result targets.

This means the outer form decides what kind of objects are returned.

#+begin_src lisp
(headings ...)
(links ...)
(files ...)
#+end_src

Default shorthand:

#+begin_src lisp
(todo "NEXT")
#+end_src

is equivalent to:

#+begin_src lisp
(headings
  (todo "NEXT"))
#+end_src

So:

- ~(headings ...)~ returns headings.
- ~(links ...)~ returns links.
- ~(files ...)~ returns files / root nodes.
- bare predicates default to heading queries.

** Why this is needed

The same concept can be used in two different ways.

Example 1: return headings that link to ~notes.org~.

#+begin_src lisp
(headings
  (links-to (file "notes.org")))
#+end_src

Example 2: return the links that point to ~notes.org~.

#+begin_src lisp
(links
  (target (file "notes.org")))
#+end_src

These are different result sets:

- first returns source headings
- second returns link rows

** Boolean composition

Boolean composition works inside every target.

#+begin_src lisp
(headings
  (and
    (todo "NEXT")
    (tags "project")))

(links
  (and
    (link-type "file")
    (target (file "notes.org"))))

(files
  (and
    (file-title "Projects")
    (file-modified :from -7)))
#+end_src

Supported boolean forms:

#+begin_src lisp
(and ...)
(or ...)
(not ...)
#+end_src

** Heading queries

Heading queries return headings.

Examples:

#+begin_src lisp
(headings
  (todo))

(headings
  (and
    (todo "NEXT")
    (tags "project")))

(headings
  (and
    (heading "sqlite")
    (property "OWNER" "Alice" :inherit t)))
#+end_src

Bare heading predicate shorthand:

#+begin_src lisp
(todo "NEXT")
#+end_src

means:

#+begin_src lisp
(headings
  (todo "NEXT"))
#+end_src

** Link filters inside heading queries

Inside a heading query, link-related predicates filter headings.

They answer:

- does this heading contain such a link?
- does anything link to this heading?
- does this heading link to such a target?

*** ~has-link~

Matches headings that contain at least one link.

#+begin_src lisp
(headings
  (has-link))
#+end_src

With link predicate:

#+begin_src lisp
(headings
  (has-link
    (link-type "file")))
#+end_src

Means:

- return headings containing at least one file link.

*** ~links-to~

Matches headings that have outgoing links to a target.

#+begin_src lisp
(headings
  (links-to (file "notes.org")))
#+end_src

Means:

- return headings that contain a link pointing to ~notes.org~.

Target can be a file query:

#+begin_src lisp
(headings
  (links-to
    (file :title "Notes")))
#+end_src

Target can be a heading query:

#+begin_src lisp
(headings
  (links-to
    (heading
      (property "CUSTOM_ID" "query-model"))))
#+end_src

*** ~linked-from~

Matches headings that have backlinks from a source.

#+begin_src lisp
(headings
  (linked-from (file "index.org")))
#+end_src

Means:

- return headings that are linked from ~index.org~.

Any backlink:

#+begin_src lisp
(headings
  (linked-from :any))
#+end_src

Means:

- return headings that have at least one backlink.

** Link queries

Link queries return links.

The outer form is:

#+begin_src lisp
(links ...)
#+end_src

A link query filters link rows by:

- link attributes
- source location
- resolved target
- broken/resolved status

*** All links

#+begin_src lisp
(links)
#+end_src

*** By link type

#+begin_src lisp
(links
  (link-type "file"))

(links
  (link-type "id"))

(links
  (link-type "custom-id"))
#+end_src

*** By description

#+begin_src lisp
(links
  (link-description "Project"))

(links
  (link-description-regexp "Proj.*"))
#+end_src

*** By raw target

#+begin_src lisp
(links
  (link-target "notes.org"))

(links
  (link-target-regexp "notes.*\\.org"))
#+end_src

*** By resolved/broken status

#+begin_src lisp
(links
  (resolved))

(links
  (broken))
#+end_src

*** By source

Use ~source~ to filter where the link is located.

Source can be a file query:

#+begin_src lisp
(links
  (source
    (file "index.org")))
#+end_src

Source can be a heading query:

#+begin_src lisp
(links
  (source
    (heading
      (tags "project"))))
#+end_src

Source can combine predicates:

#+begin_src lisp
(links
  (source
    (and
      (file "projects.org")
      (heading "Dashboard"))))
#+end_src

*** By target

Use ~target~ to filter where the link points.

Target can be a file query:

#+begin_src lisp
(links
  (target
    (file "notes.org")))
#+end_src

Target can be a heading query:

#+begin_src lisp
(links
  (target
    (heading
      (property "CUSTOM_ID" "query-model"))))
#+end_src

Target can be any resolved target:

#+begin_src lisp
(links
  (target :any))
#+end_src

*** Backlinks as link query

All links pointing to ~notes.org~:

#+begin_src lisp
(links
  (target
    (file "notes.org")))
#+end_src

All links pointing to headings with tag ~project~:

#+begin_src lisp
(links
  (target
    (heading
      (tags "project"))))
#+end_src

*** Outgoing links as link query

All links from ~index.org~:

#+begin_src lisp
(links
  (source
    (file "index.org")))
#+end_src

All links from project headings:

#+begin_src lisp
(links
  (source
    (heading
      (tags "project"))))
#+end_src

*** Source and target together

#+begin_src lisp
(links
  (and
    (source
      (file "index.org"))
    (target
      (file "notes.org"))))
#+end_src

Means:

- return links located in ~index.org~
- that point to ~notes.org~

*** Source, target, and link attributes

#+begin_src lisp
(links
  (and
    (link-type "file")
    (link-description "Notes")
    (source
      (heading
        (tags "dashboard")))
    (target
      (file "notes.org"))))
#+end_src

** Files queries

Files queries return file/root nodes.

#+begin_src lisp
(files)
#+end_src

Examples:

#+begin_src lisp
(files
  (file "projects"))

(files
  (file-title "Projects"))

(files
  (file-modified :from -7))

(files
  (keyword "TITLE" "Projects"))

(files
  (property "CATEGORY" "work" :with-root t))
#+end_src

** File/root as context

Files can also appear as root nodes in outline output.

Example outline output:

#+begin_src json
[
  {
    "kind": "file",
    "matched": false,
    "path": "notes.org",
    "title": "Notes",
    "properties": {
      "CATEGORY": "notes"
    },
    "children": [
      {
        "kind": "heading",
        "matched": true,
        "title": "SQLite FTS notes"
      }
    ]
  }
]
#+end_src

Important:

- file/root nodes can have title
- file/root nodes can have properties
- file/root nodes can have keywords
- predicates must define whether root values count

Use:

#+begin_src lisp
:with-root t
#+end_src

Example:

#+begin_src lisp
(headings
  (property "CATEGORY" "notes" :inherit t :with-root t))
#+end_src

** Important naming decision

Use these root forms:

#+begin_src lisp
(headings ...)
(links ...)
(files ...)
#+end_src

Avoid relying only on predicates like org-ql.

Reason:

- It must be clear whether the query returns headings, links, or files.
- The same relationship can be used either to filter headings or to return links.
- This makes backlinks/outgoing links understandable.
