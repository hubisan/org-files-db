* Results

** Approach

- Built a deterministic 24-variant benchmark matrix covering the version-8 index baseline, six individual candidates, and the combined profile across no-FTS, title-FTS, and body-FTS modes.
- Corrected profile comparability by canonicalizing relative work directories, using equal-length internal corpus paths, and requiring positive path and directory lookup results.
- Measured read plans and latency, database size, rebuild duration, incremental planning/application cost, and semantic equivalence on the 1,000-file release corpus.
- Applied only the accepted subset to the authoritative schema and preserved the historical version-8 benchmark matrix by reconstructing that index set before each profile.

** Measurement decision

| Candidate | Decision | Rationale |
|-----------+----------+-----------|
| ~candidate-add-files-path-lower~ | Accepted | About 65-66 percent median improvement for exact case-insensitive file-path lookup; planner used the expression index. |
| ~candidate-add-headings-title-lower~ | Accepted | About 68-70 percent median improvement for exact file-title lookup; planner used the expression index. |
| ~candidate-add-links-resolution-status~ | Rejected | No stable meaningful read improvement and a measurable incremental-write penalty. |
| ~candidate-remove-tags-heading~ | Accepted | Redundant with the primary-key index beginning with ~heading_id~. |
| ~candidate-remove-keywords-heading~ | Accepted | Redundant with the unique index beginning with ~heading_id~. |
| ~candidate-remove-repeaters-timestamp~ | Accepted | Duplicated the index implied by ~timestamp_id UNIQUE~. |
| ~combined-candidates~ | Rejected as measured | Included the rejected link-status index; only the accepted subset was applied. |

- All 24 variants preserved result counts and completed semantic equivalence checks.
- The accepted subset adds an estimated net 232 KiB on the 1,000-file corpus.

- The exact accepted subset was not a standalone benchmark profile; the combined profile also contained the rejected resolution-status index.
