** DONE [2026-06-23 Tue 20:45] Verify and complete raw keyword parsing contract

Goal:
Verify and complete raw Org keyword storage for generic Org keyword lines such as ~#+TITLE~, ~#+AUTHOR~, ~#+STARTUP~, ~#+OPTIONS~, and ~#+EXPORT_FILE_NAME~.

This task ensures that recognized Org keyword nodes are stored as raw file-level keyword facts attached to the synthetic level 0 heading, even when they appear later in the document after regular headings.

Context:
Whole-document parsed keyword collection already exists and is used for raw keyword insertion and for ~#+PROPERTY~ / ~#+CATEGORY~ normalization. This task should not reimplement keyword scanning. It should verify and complete the raw keyword contract for generic keywords.

Important distinction:
Keyword recognition is separate from keyword semantics. This task stores raw keyword facts only. It must not decide whether a keyword is globally effective, position-dependent, cumulative, last-one-wins, export-related, startup-related, or only metadata.

Scope:
- Reuse the existing parsed whole-document keyword collection.
- Store recognized keyword nodes from the whole document as raw rows in ~keywords~.
- Attach all raw keyword rows to the synthetic level 0 heading.
- Preserve keyword name and raw value.
- Normalize keyword names consistently, preferably uppercase.
- Preserve duplicate keyword rows.
- Preserve source order through ~line_number~ and/or insertion order.
- Test generic keywords before and after regular headings.
- Document the parser/indexer contract that keyword rows are file-level rows, even when the keyword appears later in the file.

Out of scope:
- Do not add a second raw-text scanner.
- Do not attach keyword rows to regular headings.
- Do not compute keyword semantics.
- Do not change ~TODO~, ~SEQ_TODO~, or ~TYP_TODO~ semantics.
- Do not change ~todo_keywords~ schema or uniqueness behavior.
- Do not change ~#+PROPERTY~ or ~#+CATEGORY~ normalization unless an existing regression test fails.
- Do not create property rows for generic keywords such as ~#+TITLE~, ~#+AUTHOR~, ~#+STARTUP~, ~#+OPTIONS~, or ~#+EXPORT_FILE_NAME~.
