,*** BUILD Preserve whitespace in CUSTOM_ID and Org ID matching

Problem:

Whitespace is significant in Org =CUSTOM_ID= and =ID= property values. The resolver currently treats surrounding whitespace as normalization input, but that is not correct for bracket links.
