* Planning

** Problem summary

Links are currently scanned from raw text without structural ignored-region filtering, and indexed links are hard-wired to ~normal~ source context.

** Goals

- Suppress link extraction inside ignored Org regions.
- Annotate extracted links with explicit parser-owned ~source_context~.
- Preserve the existing DB schema and rebuild flow.

** Non-goals

- No DB schema change.
- No target resolution.
- No bracket, angle, or plain-link semantic rewrite beyond ignored-region handling.

** Architecture

- Keep ~LinkScanContext~ scanner-side and limited to ignored byte ranges.
- Use Orgize in the adapter to collect ignored ranges and allowed context spans.
- Annotate parsed links after scanning via byte-position lookup.

** Execution plan

- Extend ~ParsedLink~ with a source-context enum and DB-string conversion.
- Collect ignored ranges and context spans from Orgize structure.
- Scan with ignored ranges, then annotate links with resolved source context.
- Update indexer/tests/manual fixtures/task notes.

** Risks & assumptions

- Inline source/export are ignored only where Orgize exposes reliable structure.
- ~JUSTIFY~ is the only special block mapped to ~justify_block~.
- Heading context applies only to the headline title line.
