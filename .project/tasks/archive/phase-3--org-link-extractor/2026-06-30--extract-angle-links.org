=BUILD with 5.4 medium=

Goal:

- Extract supported Org angle links and store them as raw source facts.

Contract:

- Angle links are syntax-driven.
- Supported form: ~<type:path>~.
- The type is the substring before the first ~:~.
- The type does not need to be predefined.
- Unknown explicit types are preserved as their ASCII-lowercase prefix.
- The closing ~>~ must be on the same line.
- Spaces inside the path are allowed.
- Store ~format = angle~.
- Store ~raw~ exactly, including surrounding angle brackets.
- Store ~raw_target~ as the content inside the angle brackets.
- Store ~raw_description = NULL~.
- Store ~link_type~ as the lowercase type prefix.
- Store ~path~ as the part after the first ~:~.
- Split ~path::search_option~ only for file-like types.
- File-like angle types for Phase 3 are:
  - ~file~
  - ~file+sys~
  - ~file+emacs~
- Do not split search options for ~id~, ~attachment~, ~docview~, ~shell~, unknown, or arbitrary custom types in Phase 3.
- Do not execute or resolve action-like protocols.
- Do not resolve file paths.
- Do not populate Phase 4 resolution fields.
#+end_src
