- Resolve same-file CUSTOM_ID links classified by Phase 3 as fuzzy links.

  - ~link_type = fuzzy~

  - ~CUSTOM_ID~

  - normalized value after removing ~#~ and trimming leading/trailing whitespace
- Search scope:
  - non-root headings in the source file only
- Value comparison:
  - case-insensitive
- No-match status:
  - ~broken~
- Duplicate-match behavior:
  - select the first matching heading in document order

- On one or more matches, set:
  - ~target_file_id~ to the source file id

  - ~target_id = NULL~
  - ~resolution_status = resolved~
  - ~resolution_diagnostic = NULL~

  - ~target_file_id~ to the source file id
  - ~target_heading_id = NULL~
  - ~target_custom_id~ to the normalized CUSTOM_ID target value
  - ~target_id = NULL~
  - ~resolution_status = broken~
  - ~resolution_diagnostic = custom id not found~
