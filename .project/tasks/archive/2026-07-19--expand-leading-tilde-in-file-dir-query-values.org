Goal:

- Allow ~file-dir~ query values beginning with ~~ to refer to the current user's home directory.
- Expand the leading ~~ from the process ~HOME~ environment variable before evaluating the predicate.
- Reuse the same path-expansion semantics as ~file-path~.
- Keep stored file paths and directories unchanged.

Current behaviour:

- ~file-dir~ query arguments are treated as literal text.
- No home-directory expansion is applied.
- Therefore, a query such as:

#+begin_src lisp
(headings
  (file-dir
    "~/projects/coding/org-files-db/.project/manual-tests/query-model/org/headings/path-zone/deep-zone"))
#+end_src

does not match files stored below:

#+begin_src text
/home/hubisan/projects/coding/org-files-db/.project/manual-tests/query-model/org/headings/path-zone/deep-zone
#+end_src

Required semantics:

- Expand a query value consisting only of ~~ to the value of ~HOME~.
- Expand a query value beginning with ~~/~ by replacing the leading ~~ with ~HOME~.

Example:

#+begin_src text
HOME=/home/hubisan
~/projects/example
-> /home/hubisan/projects/example
#+end_src

- Perform expansion only when ~~ is the first path component.
- Leave ~~ occurring elsewhere unchanged.
- Do not support named-user expansion such as ~~alice/projects~.
- Do not invoke a shell.
- Do not canonicalise paths, resolve symbolic links, or require the directory to exist.
- Do not modify values stored in the database or returned in query results.

Matching semantics:

- Apply home-directory expansion before evaluating the normal ~file-dir~ matching behaviour.
- Preserve all existing ~file-dir~ semantics after expansion.
- Apply expansion consistently to:
  - default matching
  - exact matching, if supported
  - regular-expression matching, if supported
  - multiple supplied values, if supported
- Expand every supplied directory argument independently.

Expected example:

With:

#+begin_src text
HOME=/home/hubisan
#+end_src

#+end_src

Shared implementation:

- Use the same leading-home expansion helper as ~file-path~.
- Keep expansion specific to path predicates.
- Do not add ~~ expansion to generic text predicates.
- Ensure ~file-path~ and ~file-dir~ cannot develop different expansion rules.

Implementation tasks:
