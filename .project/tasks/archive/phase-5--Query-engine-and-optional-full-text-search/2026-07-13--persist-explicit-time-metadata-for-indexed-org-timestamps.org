Depends on:

- Complete date-only and datetime query-bound semantics

Goal:

- Persist whether each indexed Org timestamp contained an explicit time.
- Allow date-only timestamps and explicit midnight timestamps to be distinguished reliably.

Rules:

- Explicit-time presence must be derived while parsing or indexing the original Org timestamp.
- Explicit-time presence must not be inferred from the encoded timestamp value.
- A date-only timestamp has ~has_time = 0~.
- A timestamp containing an explicit hour and minute has ~has_time = 1~, including explicit midnight.
- Missing or unavailable timestamp facts may use ~NULL~ where required by migration or compatibility constraints.
- Existing timezone-naive timestamp values must remain unchanged.
- All timestamp-bearing persisted facts needed by ~:with-time~ filtering must expose equivalent explicit-time metadata.

Possible planning-column extension:

#+begin_src sql
scheduled_has_time INTEGER
    CHECK (scheduled_has_time IN (0, 1) OR scheduled_has_time IS NULL),

deadline_has_time INTEGER
    CHECK (deadline_has_time IN (0, 1) OR deadline_has_time IS NULL),

closed_has_time INTEGER
    CHECK (closed_has_time IN (0, 1) OR closed_has_time IS NULL)
#+end_src

The generic timestamp storage used by ~ts~, ~ts-active~, and ~ts-inactive~ must receive equivalent explicit-time metadata.

Acceptance criteria:

- The database schema persists explicit-time information for planning timestamps.
- The database schema persists explicit-time information for generic timestamps used by timestamp query predicates.
- Indexing a date-only timestamp stores ~has_time = 0~.
- Indexing a timestamp with an explicit time stores ~has_time = 1~.
- An explicit midnight timestamp stores ~has_time = 1~.
- Existing encoded timestamp values remain unchanged.
- Reindexing populates explicit-time facts consistently.
- Schema and migration tests cover existing databases where applicable.
- Indexer tests cover scheduled, deadline, closed, active, and inactive timestamps.
- Date-only timestamps and explicit midnight timestamps are distinguishable from persisted facts.
