* Planning

** Problem summary

The previous microbenchmark shows that relation-driven metadata matching beats heading-driven correlated ~EXISTS~ in every measured case.

The microbenchmark stops after matched heading IDs reach Rust.

It does not include enrichment, decoding, Rust result shaping, or complete production query latency.

The production decision therefore needs one controlled end-to-end comparison.

** Goals

- Add a controlled complete-query A/B benchmark for all four metadata predicate families.
- Test approximately 1%, 10%, 50%, and 100% selectivity.
- Require exact final query result equality before timing comparisons are accepted.
- Use ~10'000~ and ~50'000~ headings as the primary production-size evidence.
