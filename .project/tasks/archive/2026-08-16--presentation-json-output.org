** Architecture

Add one presentation response builder to ~PresentationSpec~.

The builder creates normal rows with ~row_context = null~. It then runs sorting and layout before it returns ~PresentationResponse~.

Keep presentation query execution on one read transaction. Read index state and query results from that transaction.

Use ~serde_json::to_writer~ for compact presentation JSON. Keep ~serde_json::to_writer_pretty~ for normal query JSON.

Reject non-null ~row_source~ during response building until the row-expansion task implements it.
