- =CHANGED= Rebuild now prepares each file from one verified source snapshot and stores its SHA-256 content hash.
- =ADDED= Configuration now supports global file exclusions and directory-local file or tree exclusions for discovery.
- =CHANGED= Discovery now uses byte-preserving canonical file identities, follows file and directory symlinks safely, and treats missing explicit files separately from unavailable directory roots.
- =FIXED= Legacy databases now keep file identity =NULL= until a rebuild rediscovers the canonical Unix path instead of storing an invalid identity value.
- =CHANGED= =headings=, =links=, =query=, and =search= now emit JSON by default; =--format json= is available and =--json= remains supported.
- =CHANGED= FTS title search now indexes source headline text, so TODO keywords, priority cookies, and statistics cookies can match after rebuilding the index.
- =ADDED= Rebuild now resolves file-context =CUSTOM_ID= links such as =[[file:other.org::#custom-id]]= against properties in the resolved target file.
- =ADDED= =orgfdb links --json= now exposes stored link-resolution fields alongside the existing raw link source facts.
- =ADDED= Rebuild now resolves Org =id:...= links against indexed =ID= properties, reporting missing IDs as =unresolved= and duplicate IDs as =ambiguous=.
- =ADDED= Rebuild now resolves same-file bracket =CUSTOM_ID= links such as =[[#custom-id]]= against source-file heading properties.
- =FIXED= Resolver matching for =CUSTOM_ID= and Org =ID= now preserves leading and trailing whitespace in bracket-link targets instead of trimming it away.
- =FIXED= Star heading-title matching now handles Unicode case-insensitive pairs such as =Ärger= and =ärger= for both file and same-file star links.
- =FIXED= Star heading-title link resolution now trims outer whitespace and matches case-insensitively for both =file:...::*Heading= and same-file =[[*Heading]]= links.
- =CHANGED= Rebuild now resolves file-like links to known indexed files and distinguishes missing in-universe targets from outside-universe targets.
- =CHANGED= Rebuild now shortens resolver diagnostics to stable category labels and keeps successful duplicate heading matches silent.
- =CHANGED= Rebuild now runs a deterministic link-resolution fallback pass that marks currently unsupported links explicitly instead of leaving resolver-owned state untouched.
- =CHANGED= Added explicit link resolution state columns to the SQLite =links= table while keeping raw link source facts immutable.
- =ADDED= Evaluated minimal Orgize adapter.
- =ADDED= Added parser-owned document, heading, planning, property, and diagnostic types plus contract tests for backend-independent parser behavior.
- =ADDED= Added a fresh Rust crate scaffold with parser, indexer, DB, query, config, and CLI module boundaries for the new parser-first architecture.

** Changelog Entry Types

- =ADDED= :: Use for new features, new functionality, or newly introduced behavior.
- =CHANGED= :: Use for modifications to existing behavior.
- =FIXED= :: Use for bug fixes or incorrect behavior that now works correctly.
- =REMOVED= :: Use for removed functionality, deleted features, or deprecated behavior that no longer exists.

** Rules

- Use one bullet per change.
- Keep entries short and clear.
- Write for users, not developers.
- Do not include unfinished work.
- Do not include internal refactorings unless they affect users.
- Add newest entries at the top of the =Unreleased= section.
- Use uppercase entry types:
  - =ADDED=
  - =CHANGED=
  - =FIXED=
  - =REMOVED=
- Keep wording simple and direct.
- Prefer describing the visible result instead of implementation details.

** Releases

When creating a release:
- move entries from =Unreleased= into a version section
- keep the same bullet format
- use the following heading format:
  #+begin_src org
    ,* 0.1.0 - YYYY-MM-DD
  #+end_src

** Example Release

#+begin_src org
  ,* 0.1.0 - 2026-05-22

  - =CHANGED= Clarified AI workflow and commit rules.
  - =FIXED= Fixed incorrect WAIT status handling.
  - =REMOVED= Removed outdated setup instructions.
#+end_src
