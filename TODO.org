** TODO memchr-basierten Link Parser implementieren

Wichtig:

- Unbedingt memchr nutzen.

Vorgehen:

- Fast scanning:
  - Use memchr or SIMD search to jump to the next candidate start byte:
    - =[= for bracket links
    - =<= for angle links
    - =:= for plain typed links, then scan backwards/forwards to validate TYPE

- Bracket links:
  - After seeing =[[=, scan forward for =]= candidates and check for =][= or =]]= while applying the odd/even backslash rule.
  - Enforce “no unescaped [ or ] inside TARGET” to reject cases like =[[[]]]= early.

- Always ensure progress on failure:
  - If =[[= parse fails, advance by 1 byte, not 2, so later overlapping patterns can still be found.

Akzeptanzkriterien:

- Link Parser erkennt gültige Links.
- Ungültige Links werden sauber übersprungen.
- Parser bleibt nie hängen.
- memchr wird verwendet.
- Tests decken Bracket, Angle und Plain Links ab.

** TODO Org-mode Link Unescape nachbilden

Ziel:

- Link und Description sollen sauber unescaped werden.

Org-mode Referenz:

#+begin_src elisp
(defun org-link-unescape (link)
  "Remove escaping backslash characters from string LINK."
  (replace-regexp-in-string
   (rx (group (one-or-more "\\")) (or string-end (any "[]")))
   (lambda (_)
     (concat (make-string (/ (- (match-end 1) (match-beginning 1)) 2) ?\\)))
   link nil t 1))
#+end_src

Sonderfälle:

#+begin_example

[[ wird zu [[] [[file:.gitignore][[[]]
][ wird zu ][] [[file:.gitignore][][]]
#+end_example

Akzeptanzkriterien:
