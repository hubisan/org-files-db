#+TITLE: Contributing
#+STARTUP: showall

* Report a problem or request a change

Open an issue in the project issue tracker.

Before you open a new issue:

- Search open and closed issues for the same problem.
- Check active pull requests for related work.
- Describe the expected behavior and the current behavior.
- Include a small reproduction when practical.

* Submit a pull request

Keep each pull request focused on one feature or correction.

Before you submit it:

- Open or reference the related issue.
- Add or update tests for changed behavior.
- Update user or contributor documentation when the public contract changes.
- Update [[./CHANGELOG.org][CHANGELOG.org]] when the change needs a release note.
- Run the repository checks.

Read [[./docs/README.org][Documentation]] to find the correct document for a public fact.

* Tests

Run the standard repository check:

#+begin_src shell
make ci
#+end_src

If the check fails, correct the error before you submit the pull request.
