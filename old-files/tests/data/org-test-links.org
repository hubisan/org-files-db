* Ignored Links

Org-mode typically ignores links under certain circumstances (e.g., within comments or code blocks). While my implementation generally follows the parsing rules established by ~org-element-parse-buffer~, I made a deliberate exception: Links found within the Property Drawer (:PROPERTIES:) are also parsed, which deviates from the standard logic.

** OK Escape Chars

Specification: [[https://www.gnu.org/software/emacs/manual/html_node/org/Link-Format.html][Link Format (The Org Manual)]]

#+BEGIN_QUOTE
Some ‘\’, ‘[’ and ‘]’ characters in the LINK part need to be “escaped”, i.e., preceded by another ‘\’ character.  More specifically,
the following characters, and only them, must be escaped:

  1. all ‘[’ and ‘]’ characters,
  2. every ‘\’ character preceding either ‘]’ or ‘[’,
  3. every ‘\’ character at the end of the link.

   Functions inserting links (see *note Handling Links::) properly
escape ambiguous characters.  You only need to bother about the rules
above when inserting directly, or yanking, a URI within square brackets.
When in doubt, you may use the function ‘org-link-escape’, which turns a
link string into its escaped form.

#+BEGIN_SRC elisp :results value verbatim code
  (defun my-org-element-list-links-with-path ()
    "Return all Org links with outline path + description text."
    (let* ((ast (org-element-parse-buffer))
           (results '()))

      (cl-labels
          ((get-path (pos)
             (save-excursion
               (goto-char pos)
               (condition-case nil
                   (org-get-outline-path t)
                 (error nil))))
           (get-desc (lnk)
             (let ((cb (org-element-property :contents-begin lnk))
                   (ce (org-element-property :contents-end   lnk)))
               (when (and cb ce)
                 (buffer-substring-no-properties cb ce)))))

        (org-element-map ast 'link
          (lambda (lnk)
            (let* ((pos   (org-element-property :begin lnk))
                   (path  (get-path pos))
                   (type  (org-element-property :type lnk))
                   (raw   (org-element-property :raw-link lnk))
                   (path2 (org-element-property :path lnk))
                   (desc  (get-desc lnk)))
              (push (list :outline path
                          :type type
                          :raw raw
                          :path path2
                          :desc desc)
                    results)))))

      (nreverse results)))

  (with-current-buffer "org-test-links.org"
    (my-org-element-list-links-with-path))
#+END_SRC
