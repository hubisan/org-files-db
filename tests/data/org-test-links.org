* External Links

Specification: [[https://www.gnu.org/software/emacs/manual/html_node/org/External-Links.html][External Links (The Org Manual)]]

Built-in links are stored. External links can also be plain, as long as they start with the link type.

** OK File
If a file link links to a heading in an org file which is tracked, it is linked to the target heading.

  - [[file:/etc]]
  - [[file:/etc][description: /etc]]
  - [[/etc]]
  - file+sys:/etc
  - file+emacs:/etc
  - [[file+emacs:/etc]]
  - [[file+sys:/etc][desription: file+sys:/etc]]

  - file:/etc/

* NOT_IMPLEMENTING Link Abbrevations

Specification: https://orgmode.org/manual/Link-Abbreviations.html

Long URLs can be abbreviated like ~[[linkword:tag][description]]~. But to find out the URL the variable ~org-link-abbrev-alist~ is needed. This is very rare so I won't implement it.

Specification (at the end): [[https://www.gnu.org/software/emacs/manual/html_node/org/External-Links.html][External Links (The Org Manual)]]

Plain URIs are recognized only for a well-defined set of schemes. Unlike URI syntax, they cannot contain parenthesis or white spaces, either. URIs within angle brackets have no such limitation.

* Ignored Links

Org-mode typically ignores links under certain circumstances (e.g., within comments or code blocks). While my implementation generally follows the parsing rules established by ~org-element-parse-buffer~, I made a deliberate exception: Links found within the Property Drawer (:PROPERTIES:) are also parsed, which deviates from the standard logic.

** Links to Ignore

*** OK Text marked as Verbatim or Code

Inside ~ ~https://orgmode.org~
Inside = =https://orgmode.org=

*** OK Code Blocks & Inline Code Blocks

Specification: [[https://orgmode.org/manual/Structure-of-Code-Blocks.html][Structure of Code Blocks (The Org Manual)]]

#+BEGIN_SRC emacs-lisp
  [[https://www.example.com][no real link]]
  https://www.example.com
#+END_SRC

src_elisp{"https://orgmode.org"} {{{results(=https://orgmode.org=)}}} 
src_elisp[:results raw]{"https://orgmode.org"}

*** OK Example Blocks & Example Lines

Specification: [[https://orgmode.org/manual/Literal-Examples.html][Literal Examples (The Org Manual)]]

#+BEGIN_EXAMPLE
  [[https://www.example.com][no real link]]
  https://www.example.com
#+END_EXAMPLE

When lines starts with colon:
: [[https://www.example.com][no real link]]
: https://www.example.com 

*** OK Comments & Comment Blocks

Specification: [[https://orgmode.org/manual/Comment-Lines.html][Comment Lines (The Org Manual)]]

#+BEGIN_COMMENT
[[https://orgmode.org][link in comment block]]
#+END_COMMENT

When line starts with # (commented):
# [[mailto:emacs-orgmode@gnu.org]]
# file:src/
# [[https://orgmode.org]]

*** OK Export Blocks

Specification:

- [[https://orgmode.org/manual/Quoting-HTML-tags.html][Quoting HTML tags (The Org Manual)]]
- [[https://orgmode.org/manual/Quoting-LaTeX-code.html][Quoting LaTeX code (The Org Manual)]]
- [[https://www.gnu.org/software//emacs/manual/html_node/org/ASCII_002fLatin_002d1_002fUTF_002d8-export.html][ASCII/Latin-1/UTF-8 export (The Org Manual)]]
- [[https://www.gnu.org/software/emacs/manual/html_node/org/Beamer-specific-syntax.html][Beamer specific syntax (The Org Manual)]]
- [[https://www.gnu.org/software/emacs/manual/html_node/org/Quoting-Texinfo-code.html][Quoting Texinfo code (The Org Manual)]]

All export blocks starting with ~#+BEGIN_EXPORT~.

#+BEGIN_EXPORT LATEX
https://orgmode.org
[[https://orgmode.org][link in latex block]]
#+END_EXPORT

#+BEGIN_EXPORT HTML
https://orgmode.org
[[https://orgmode.org][link in html block]]
#+END_EXPORT

And the inline version:

@@html:https://orgmode.org@@
@@latex:https://orgmode.org@@
